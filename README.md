# Wordle

A five letter word guessing game with six tries and colour feedback.

## Features

- A bank of forty-eight five letter words
- Green for a letter in the right place, yellow for a letter in the wrong place
- Keyboard colours track the letters you have used
- Guess validation and a shake animation for bad entries
- Physical keyboard and on-screen keyboard support
- New word button
- A How to play popup explains the rules

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
